# Tour animado do produto

[Voltar ao showcase](../../README.md) · [English](README.en.md)

O arquivo [product-tour.gif](product-tour.gif) apresenta quatro capturas reais em sequência, com duração total de 16 segundos e repetição automática. As legendas estão em português e inglês.

1. Diário no desktop: `assets/screenshots/daily-dashboard-desktop.png`.
2. Busca no celular: `assets/screenshots/food-search-mobile.png`.
3. Refeições favoritas: `assets/screenshots/favorite-meals-mobile.png`.
4. Registro individual offline: recorte superior de `assets/screenshots/offline-food-entry-mobile.png`, identificado na animação.

O GIF é uma apresentação das capturas existentes, não uma gravação de interação. Não há cliques simulados nem transições de estado fabricadas. As capturas vêm de diferentes versões de desenvolvimento; consulte as [notas de origem](../screenshots/README.md).

A animação tem 960 × 720 pixels. O quadro offline destaca o aviso de que o lote exige conexão e a ação separada para registro individual offline.
